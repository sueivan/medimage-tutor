# MedImage Tutor V0.2.1

本版修复 V0.2 “病例载入中”问题：病例教学内容直接写入页面，不再依赖首次 `fetch JSON`。

## 教学流程
1. 认识阅片器
2. 认识正常结构
3. 发现异常
4. 定位病灶
5. 描述征象
6. 提交后才解锁专家解析
7. 带着解析再次阅片

## 覆盖现有版本
将 `index.html`、`style.css`、`app.js` 上传到原 `medimage-tutor` 仓库根目录并覆盖同名文件即可。
`cases/` 旧文件保留也不会影响 V0.2.1。

## 数据架构
原始 MRI 不存入 GitHub；通过 IDC Viewer 远程加载。

## 医疗边界
仅供医学教育与影像判读训练，不用于临床诊断。
